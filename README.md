# Fauget

## Group

### Pagina web para la venta de ropa

### Para ingresar con una cuenta de administrador, se puede crear un usuario normalmente y luego en inspeccionar y en local storage se puede cambiar el valor de rol de "user" a "admin" para poder entrar con los permisos completos sobre la página desde el inicio de sesión

### El programa tiene un guardado en forma de LocalStorage

### No cuenta con información previa guardada, sin embargo, permite crear cuentas, agregar categorias, productos y pedidos que quedaran guardados en LocalStorage una vez creados

### Tambien permite editar esta información guardada en caso de querer hacer cambios en ellos
